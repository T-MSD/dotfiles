# Neovim

[LazyVim](https://www.lazyvim.org)-based config, linked to `~/.config/nvim` by the repo's `install.sh`.

## Layout

```
init.lua                 bootstraps lua/config/lazy.lua
lazyvim.json             enabled LazyVim extras
lazy-lock.json           pinned plugin versions
lua/config/
  lazy.lua               lazy.nvim bootstrap and leader keys
  options.lua            editor options
  keymaps.lua            custom keymaps
  autocmds.lua           custom autocommands (none yet)
  theme.lua              generated by `theme`, git-ignored
lua/plugins/             plugin specs and overrides
lua/plugins/themes/      colorscheme plugins and the active-theme loader
```

## LazyVim extras

- `formatting.prettier`
- `lang.json`, `lang.ruby`, `lang.tailwind`, `lang.typescript`
- `linting.eslint`

Manage them with `:LazyExtras`. The list is stored in `lazyvim.json`.

## Plugins and overrides

| File | Purpose |
|---|---|
| `colorizer.lua` | Inline colour previews (`catgoose/nvim-colorizer.lua`) |
| `live-preview.lua` | Browser preview for Markdown, HTML, AsciiDoc and SVG |
| `lspconfig.lua` | `pyright`; `ruby_lsp` from rbenv instead of Mason, so each project uses its own Ruby |
| `lualine.lua` | Extra status line component |
| `mason.lua` | Ensures `stylua`, `shellcheck`, `shfmt`, `flake8` |
| `snacks.lua` | Explorer shows hidden and git-ignored files by default |
| `telescope.lua` | Prompt on top, ascending sort; `<leader>fp` finds plugin files |
| `treesitter.lua` | Extends LazyVim's parser list |
| `trouble.lua` | Uses diagnostic signs |

## Theme

`lua/plugins/themes/active.lua` reads `config.theme`, which the `theme` command generates (see the root [README](../README.md#theme-switching)). It sets the LazyVim colorscheme and background from that file, and falls back to gruvbox dark hard if it is missing.

`:ThemeReload` re-reads the file and applies it without restarting. `theme` calls it on every running Neovim instance.

Each family has a plugin spec in `lua/plugins/themes/`: gruvbox, jellybeans, melange, rose-pine, tokyonight, vesper.

## Options

Highlights from `lua/config/options.lua`:

- Relative line numbers, 4-space indentation, soft wrap at word boundaries.
- `scrolloff = 25`, so the cursor stays near the middle.
- No swap or backup files; persistent undo in `stdpath("data")/undodir`.
- System clipboard via `unnamedplus`.
- Global status line (`laststatus = 3`).

## Keymaps

Leader is `<Space>`. These are on top of [LazyVim's defaults](https://www.lazyvim.org/keymaps).

### Editing

| Keys | Mode | Action |
|---|---|---|
| `jk`, `kj` | insert | Exit insert mode |
| `x` | normal | Delete character without yanking |
| `p` | visual | Paste without overwriting the register |
| `<` / `>` | visual | Indent and keep the selection |
| `<A-j>` / `<A-k>` | visual | Move selection down / up |
| `<leader>j` | normal | Replace word under cursor (repeat with `.`) |
| `<leader>y` / `<leader>Y` | normal, visual | Yank to system clipboard |
| `<leader>+` / `<leader>-` | normal | Increment / decrement number |
| `<leader>sn` | normal | Save without formatting |
| `<C-q>` | normal | Quit window |

### Navigation and windows

| Keys | Action |
|---|---|
| `<C-d>` / `<C-u>` | Half-page scroll, centred |
| `n` / `N` | Next / previous match, centred |
| `<Up>` `<Down>` `<Left>` `<Right>` | Resize split |
| `<leader>v` / `<leader>h` | Split vertically / horizontally |
| `<leader>se` | Equalise splits |
| `<leader>xs` | Close split |
| `<leader>wh/j/k/l` | Move to split |
| `<leader>o` | Toggle focus between editor and explorer |
| `<leader>b` | New buffer |
| `<leader>to` / `tx` / `tn` / `tp` | New / close / next / previous tab |

### Diagnostics and git

| Keys | Action |
|---|---|
| `[d` / `]d` | Previous / next diagnostic |
| `<leader>d` | Diagnostic float |
| `<leader>q` | Diagnostics to location list |
| `<leader>do` | Toggle diagnostics in the buffer |
| `<leader>ud` | Toggle RuboCop / StandardRB diagnostics only |
| `<leader>ghi` | Toggle inline diff of the whole file |

### Misc

| Keys | Action |
|---|---|
| `<leader>lw` | Toggle line wrap |
| `<leader>lp` / `<leader>lP` | Start / close Live Preview |
| `<leader>ss` / `<leader>sl` | Save / load `.session.vim` in the current directory |

## Requirements

- Neovim 0.11+
- A Nerd Font (FiraCode Nerd Font in Ghostty and WezTerm)
- `ripgrep`, `fd`, `git`
- `ruby-lsp` installed per Ruby version via rbenv, for Ruby projects
